# Codex for Tenno

Welcome to Codex for Tenno, a web application designed to help Warframe players with useful guides and resource farming information.

This project was built with Firebase Studio.

## Core Features

- **Guide Display**: Displays guides for Warframe content, such as the Steel Path or tips for beginners.
- **Guide Filtering**: Allows users to filter guides by category (e.g., Steel Path, Beginners, Warframes, Weapons).
- **Resource Farming Information**: A dedicated page with a table showing the best locations to farm important resources.
- **Multi-language Support**: The interface is available in both English and Spanish.

## Tech Stack

This application is built with a modern web stack:

- [Next.js](https://nextjs.org/) - React framework for production.
- [TypeScript](https://www.typescriptlang.org/) - For strong typing and better code quality.
- [Tailwind CSS](https://tailwindcss.com/) - For utility-first styling.
- [ShadCN/UI](https://ui.shadcn.com/) - A collection of beautifully designed, reusable components.
