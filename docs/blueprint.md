# **App Name**: Warframe Codex

## Core Features:

- Guide Display: Display guides for Warframe content, like the Steel Path or beginner tips.
- Guide Filtering: Allow users to filter guides by category (e.g., Steel Path, Beginners, Warframes, Weapons).
- Guide Search: Provide a search function for users to quickly find guides on specific topics.
- AI Guide Summarizer: AI-powered tool which automatically summarizes long guides into key bullet points. 

## Style Guidelines:

- Primary color: Deep purple (#6a3dad), inspired by the Void and Warframe's energy color aesthetic, suggesting power and mystery.
- Background color: Dark gray (#292929), a desaturated hue of the primary, providing contrast while maintaining a somber mood.
- Accent color: Electric blue (#449dd1), an analogous hue, which is used for interactive elements to draw the user's eye and suggest futuristic technology.
- Font: 'Space Grotesk', sans-serif, for both headlines and body, provides a clean, tech-forward feel appropriate for the sci-fi setting.
- Use custom icons that represent different Warframe concepts, factions, and resources.  Icons should be simple and easily recognizable, using the accent color for highlights.
- Content should be organized using a card-based layout for guides, allowing for easy scanning. The search bar and filters should be prominently displayed at the top of the page.
- Use subtle animations when transitioning between guides or displaying summaries. This should feel fluid and modern, without distracting the user from the content.
